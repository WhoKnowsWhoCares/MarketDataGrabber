# Визуализация — реестр графиков MarketData

Документ-реестр: какие графики есть, для чего каждый реализован, какой вывод из него делается, чем он рендерится и что Grafana не умеет (→ веб, P7). Макет-эталон: `docs/mockups/dashboard_v1.html` (утверждён 2026-10-28).

## Принцип

Каждая панель отвечает на **конкретный вопрос за один взгляд**. Дашборд читается сверху вниз: доверие к данным → что произошло → подтверждение тренда → риск входа → будущие катализаторы. Переключатель `$instrument` меняет ряды 2–4.

## Ряд 0 — Health: «Системе можно доверять?»

| Панель | Тип Grafana | Источник | Вывод |
|---|---|---|---|
| Свежесть данных | stat | max(bar_time) candles_1m, max(bar_date) витрины | ✅ свежие → сигналы верим; ❌ устарели → игнорируем всё ниже |
| DQ проверки | stat | dq_metrics (gap_vs_calendar, ohlc_violations) | нарушения → данные грязные |
| Витрины обновлены | stat | max(bar_date) mart_daily_metrics | витрина отстаёт → see watchdog alert |

**Поддержка:** stat-панели — нативные. ✅

## Ряд 1 — Состояние: «Что произошло сегодня?»

| Панель | Тип Grafana | Источник | Вывод |
|---|---|---|---|
| Карточка инструмента (×5, repeat по переменной) | stat (sparkline + thresholds) | mart_daily_metrics: close, ret_1d, rsi14 | кто вырос/упал за день; кто в экстремуме RSI (бейдж <30 / >70) |

**Поддержка:** stat-панель с повтором по переменной инструмента, цвет по threshold, спарклайн — нативные. ⚠️ Комбинированная «карточка как в макете» (цена + % + RSI-бейдж в одном блоке) приближается повторами stat-панелей; единый HTML-блок — только в вебе (P7).

## Ряд 2 — Тренд: «Куда движется инструмент?»

| Панель | Тип Grafana | Источник | Вывод |
|---|---|---|---|
| Close + MA20 + MA50 | timeseries, 3 запроса (format=table) | mart_daily_metrics: close, ma20, ma50 по `$instrument` | close выше обеих MA — восходящий тренд; пересечение close↔MA20 — ранний признак смены |

**Поддержка:** timeseries с несколькими series — нативные. ✅

## Ряд 3 — Объём: «Движение подтверждено?»

| Панель | Тип Grafana | Источник | Вывод |
|---|---|---|---|
| Volume бары + MA20 линий | timeseries, drawStyle override: bars для volume, line для volume_ma20 | mart_daily_metrics: volume, volume_ma20 | ratio > 2 (жёлтая подсветка threshold) — движение подтверждено объёмом; рост цены без объёма — слабое |
| Volume Ratio (stat) | stat | volume / volume_ma20 сегодня | >2 — аномалия (ядро volume-spike сигнала, P4) |

**Поддержка:** mixed bars+line через field override — нативные. ✅

## Ряд 4 — Риск: «Не поздно ли входить?»

| Панель | Тип Grafana | Источник | Вывод |
|---|---|---|---|
| RSI14 с зонами 30/70 | timeseries + thresholds (style: area — тонировка зон) | mart_daily_metrics: rsi14 | RSI >70 — вход в перекупленности = риск отката; <30 — перепроданность |
| ATR14 | stat | mart_daily_metrics: atr14 (+ range_pct) | ожидаемый размах дня → дистанция стопа |

**Поддержка:** thresholds со стилем area (тонировка полос перекупленности/перепроданности) — нативные в timeseries. ✅ Заливка «лентой» между линиями — упрощение до threshold-area, визуально эквивалентно макету.

## Ряд 5 — Контекст: «Что качнёт цену завтра?»

| Панель | Тип Grafana | Источник | Вывод |
|---|---|---|---|
| Ближайшие события | table | events: expected_date >= сегодня, типы dividend/report/expiry/trading_day | перед отчётом — ждать волатильность; экс-дивиденд — предсказуемый гэп |
| P/E / P/B / fwd DY | bargauge / barchart | fundamentals_snapshots: JSONExtractFloat(payload, 'peRatioTtm'...) | дёшево/дорого против соседей по universe |

**Поддержка:** table и bargauge — нативные. ✅ Payload-ключи camelCase: `JSONExtractFloat(payload, 'peRatioTtm')`.

## Ограничения Grafana → что уходит в веб (P7)

| Возможность | В Grafana | В вебе (P7) |
|---|---|---|
| Комбинированные карточки инструментов (цена+%+RSI-бейдж единым блоком) | ⚠️ приближение повторами stat-панелей | ✅ полный контроль вёрстки |
| Трендовые каналы (MA ± 2·ATR заливкой) | ⚠️ только две линии без заливки канала | ✅ |
| Клик по событию → фильтрация всех панелей по инструменту/дате | ⚠️ data links (частично) | ✅ |
| Произвольная типографика/брендинг отчётов | ❌ | ✅ |

## Intraday (позже, после P6 live)

Те же панели переключаются на `v_candles_5m` / `v_candles_1h` (уже есть в gold). Candlestick — нативная панель Grafana 11 (OHLC из view) — появится в intraday-дашборде. Live-обновление — авто-refresh Grafana поверх стриминга P6. Зафиксировано 2026-10-28: intraday-версия дашборда планируется после запуска live-слоя.

## Алерты (P4)

Grafana-алерты на пересечение порогов НЕ настраиваем на P3 — вместе с сигналами P4: срабатывание сигнала = аннотация на ценовом графике (annotations API) + уведомление через бота (cooldown в Redis). Пороговые подсветки на панелях уже визуализируют те же условия.

## Технические правила (извлечённые уроки)

- `format: "table"` во всех targets — плагин отвергает `time_series` (timeseries-панель рендерится из таблицы time/value/metric).
- Дефолт `time: {from: now-30d, to: now}` на уровне дашборда — иначе «no data» (данные дневные).
- Payload-ключи camelCase (`peRatioTtm`), извлечение `JSONExtractFloat`.
- Общая сеть `mdg-net` для grafana+clickhouse; новый compose-сервис требует recreate ранее запущенных.
- Дашборды matched by uid: переименование обновляет in-place, ручная копия под другим uid — навсегда устаревшая (удалить копию по её uid).
